## Verdict

**`HDDM_W (tuned)` ranks first** on the live composite. Read this as a *directional* live result (40/40 trials, not the 60–100 the synthetic benchmark uses) that corroborates the high-N synthetic + Elec2/Insects results — not a from-scratch authoritative ranking.


## Caveats, stated plainly

- Trial counts are small (40 sudden, 40 gradual) — a free-tier-budget result. More daily runs tighten it.
- Drift is *induced* by degrading the same model's request config (truncating output / spiking temperature) on a fraction of post-onset calls. The error stream is real and live, but the CAUSE is engineered config drift, not a spontaneous capability change or a genuine model swap -- a deliberate choice made because the free Groq chat models' real capability gap (~0.05) was too small to detect.
- DDM (tuned)'s `min_num_instances=150` means it only has a short pre-onset window (onset=175) to exhibit false alarms — interpret its false-alarm number with that in mind.
- Grading is exact-match on the answer letter; non-reasoning models are used so the correct/incorrect signal isn't contaminated by output-format noise.
